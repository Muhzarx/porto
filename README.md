# Portfolio Hafizd

Personal portfolio of Muhammad Hafizd Anshari, a web developer. Built with plain HTML, CSS, and a little JavaScript, with no framework and no build step.

## Live Demo

**[Open live demo](https://muhzarx.github.io/porto/)**

## Features

- Animated hero with rising name, typing role text, and a scrolling tech-stack strip
- Scroll progress bar, section reveal animations, and active navigation highlight
- Skill bars that fill and count up when they appear
- Certificate gallery with 3D hover tilt and a full-screen viewer (arrow keys and Esc supported)
- Light and dark mode toggle that remembers your choice
- One-click copy for the email address
- Responsive, keyboard accessible, and respects reduced-motion settings

## Deploy to GitHub Pages

1. Upload `index.html`, `README.md`, and the `assets` folder to the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait 1 to 2 minutes. The site will be live at `https://muhzarx.github.io/porto/`.
